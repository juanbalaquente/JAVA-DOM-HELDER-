# JAVA - Dom Helder

Repositório criado para armazenar exercícios e atividades desenvolvidas em Java durante a disciplina de **Algoritmos e Estrutura de Dados**.

## Objetivo

Este repositório tem como objetivo organizar os códigos feitos em aula e nas listas de exercícios, facilitando o acompanhamento da evolução nos estudos de programação em Java.

## Conteúdos estudados

- Entrada e saída de dados
- Variáveis e tipos primitivos
- Operadores aritméticos
- Estruturas condicionais
  - `if`
  - `else`
  - `switch case`
- Estruturas de repetição
  - `for`
  - `while`
  - `do while`
- Contadores e acumuladores
- Cálculo de média
- Tabuada
- Sequências numéricas
- Laços aninhados
- Exercícios práticos de lógica

## Estrutura do projeto

Os arquivos estão organizados principalmente na pasta `src`, contendo exercícios separados por códigos ou nomes de atividade.

Exemplo:

src/
├── C03EX05.java
├── C04EX01.java
